## 💻 Run it locally

1. ⬇️ Download or clone this repository.
2. 🖱️ Open `index.html` in any modern browser.

That's all. No installation needed! ✅

---

## ☁️ Deploy it

The file must be named `index.html`.

**🟢 GitHub Pages**
1. Create a public repository named `<your-username>.github.io`.
2. Upload `index.html`.
3. The site goes live at `https://<your-username>.github.io/` 🎉

**🟣 Render (Static Site)**
1. Push `index.html` to a GitHub repository.
2. On Render choose **New → Static Site** and select the repository.
3. Leave **Build Command** empty and set **Publish Directory** to `.`
4. Create the site and wait for the link ⏳

**🔵 Netlify**
1. Open [app.netlify.com/drop](https://app.netlify.com/drop).
2. Drag the folder that contains `index.html` onto the page.

## ✏️ Editing the content

Everything lives in `index.html`:

- 📁 **Projects:** the `P` array in the script near the end of the file
- 📝 **Text sections** (About, Skills, Contact): the HTML under `<main>`
- 🎨 **Colors:** the CSS variables at the top of the stylesheet (`--ac` is the main blue)
- 📄 **Resumes:** stored inside the file as base64 (`RESUME_B64` and `RESUME_GE`). Replace them to update a resume.
- 🔑 **Contact form key:** `W3_KEY` in the script
